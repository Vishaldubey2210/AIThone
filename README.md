**BitHead** is a high-performance, real-time cryptocurrency intelligence platform and analytics terminal. It combines live multi-currency price monitoring, interactive TradingView charts, on-chain sentiment analysis via **BitHead AI**, portfolio management, instant fiat/crypto converters, and a gamified Web3 quiz engine.

## 🌟 Key Features

### 1. 📊 Real-Time Market Screener & Screener Terminal
- **Multi-Currency Live Rates**: Instant conversion between **USD ($), INR (₹), EUR (€), GBP (£), JPY (¥), and BTC (₿)**.
- **Dynamic Category Filtering**: Seamlessly filter by **Top 10, DeFi, Layer 1, AI & Big Data, Memes, and Top 24h Gainers**.
- **Interactive Sparklines**: Live 7-day micro-trend canvas rendering for every token.
- **Fast Search & Hotkeys**: Search 100+ tokens instantly by typing `/` anywhere.
- **Watchlist Sync**: 1-click star tagging with persistent local storage.

### 2. 📈 TradingView Advanced Technical Terminal
- Embedded TradingView engine with real-time candlestick charts, intervals (`15m`, `1h`, `4h`, `1D`, `1W`), RSI indicators, and Moving Averages.
- Detailed coin modal with Circulating Supply, All-Time Highs (ATH), 24h High/Low, and Volume breakdown.

### 3. 🧠 BitHead AI Intelligence & Market Pulse
- **AI Sentiment Engine**: Synthesizes market momentum into clear sentiment scores (Bullish/Bearish/Neutral).
- **Interactive Crypto Chatbot**: Get instant answers on smart contracts, DeFi tokenomics, layer-1 blockchains, and trading strategies.
- **24h Risk Radar**: On-chain liquidity health metrics, whale transaction alerts, and trending narratives.

### 4. 💼 Personal Crypto Portfolio & PnL Tracker
- Track holdings, average purchase price, and real-time Profit & Loss ($ and %).
- Visual asset distribution breakdown powered by **Chart.js**.
- One-click sample demo portfolio loader & JSON export backup.

### 5. 🔄 Instant Crypto Converter & DCA Profit Simulator
- Swap calculator across top cryptocurrencies and fiat currencies.
- **Dollar-Cost Averaging (DCA) Simulator**: Model expected ROI based on recurring weekly/monthly investments.

### 6. 📰 Curated Crypto News Feed
- Live sentiment-tagged headlines (Bullish / Bearish / Neutral) aggregated from leading industry sources.

### 7. 🏆 Gamified Crypto Quiz 2.0
- Test blockchain mastery with timed questions, streak bonuses, dynamic point multipliers, explanations, and confetti animations on completion!

## 🛠️ Tech Stack & Architecture

- **Frontend**: Vanilla JavaScript (ES6+), HTML5, CSS3 Glassmorphism System.
- **Data Visualizations**: TradingView Technical Analysis API, Chart.js 4.4, Canvas Sparklines.
- **Styling**: Pure CSS Variables, Cyberpunk Dark / Clean Light Mode, Responsive Flexbox & CSS Grid.
- **PWA**: Service Worker caching (`sw.js`) and Web App Manifest (`manifest.json`).
- **CI/CD**: GitHub Actions for automated unit testing and GitHub Pages deployment.

## ⚡ Getting Started Locally

### Prerequisites
- Any modern web browser (Chrome, Edge, Firefox, Safari)
- Optional: Node.js (v18+) for running local dev server

### Installation & Launch

```bash
# Clone the repository
git clone https://github.com/Vishaldubey2210/AIThone.git

# Navigate to project directory
cd AIThone

# Run tests
npm test

# Launch local preview server (or simply open index.html in browser)
npx serve .
```
